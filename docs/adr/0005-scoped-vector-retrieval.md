# ADR 0005：先限定知识库，再进行精确余弦检索

- 日期：2026-10-10
- 状态：已采纳；本地验证结果见 README，真实模型检索质量待联调。
- 范围：阶段 1.4，从指定知识库返回相关文本块及来源，不生成答案。

## 问题

知识库已经保存文本向量，需要把用户的问题转换为同一模型的向量，并找出相关段落。工作空间和知识库范围必须参与数据库查询。

学习者选择先限定知识库，再取最相似的 5 段：如果先取全库前 5 段，而它们全属于知识库 B，查询 A 时再过滤会得到空结果，即使 A 中存在相关内容。范围过滤与取前几名的顺序会改变结果。

## 方案比较与选择

### 余弦距离与欧氏距离

- 余弦距离主要比较方向，减少向量长度对排序的影响；仍需用真实模型与标注语料验证相关性。
- 欧氏距离同时受方向和长度影响；适用于模型明确以该距离训练或要求使用该指标的情况。向量经过单位归一化后，两种指标的排序可以一致，但不能假定所有服务结果都已归一化。

当前选择余弦距离。返回 `metric="cosine_distance"` 和 `distance`，距离范围为 0 至 2，越小越接近；它不是答案正确率，也不自动表示证据足够。没有预先设定过滤阈值，后续使用真实语料评估后再决定。

### 精确检索与近似索引

- 精确检索比较限定范围内的全部候选向量，适合当前小规模项目建立排序与质量基线；候选增多时计算和排序开销会上升。
- HNSW、IVFFlat 等近似索引可以降低大规模检索延迟，但增加建索引、参数、内存与召回率权衡；近似索引与过滤条件结合时，还需要检查结果数量和召回行为。

当前沿用 PostgreSQL/pgvector 精确检索，不增加近似索引、重排或新的存储组件。先测量实际候选数、延迟与标注问题的召回率，再决定是否引入索引。

## 查询与事务边界

1. 请求去掉问题首尾空白，校验问题与 `top_k`。
2. 首个短事务以 `FOR SHARE` 读取并刷新知识库，核对工作空间归属及完整模型身份：接口地址、模型名称、1024 维。共享锁允许多个检索并发，阻止本事务内配置或归属被改写。
3. 没有 `ready` 文档的非空向量候选时直接返回空结果，不调用模型。知识库尚无模型配置时，响应模型和维度为空；已有配置时返回该模型与维度。
4. 结束事务、释放锁，在事务外通过已有 `EmbeddingProvider` 生成一条查询向量，并校验数量、维度及数值。
5. 第二个短事务再次取得知识库共享锁，刷新并复核归属和模型配置。模型身份变化时拒绝查询，不能拿旧查询向量检索新模型的数据。
6. SQL 同时限定工作空间、知识库、文档 `ready` 状态与非空向量，再按余弦距离升序、块 ID 升序排序，最后取 `top_k`。块 ID 用来稳定同距离结果的顺序。

检索不写入数据库。模型等待期间没有活动数据库事务。结果反映第二个短事务读取的已提交候选；当前没有原地修改原文、向量或模型配置的业务接口，也不承诺网络调用前后候选集合完全不变。

## 接口契约

`POST /api/v1/workspaces/{workspace_id}/knowledge-bases/{knowledge_base_id}/search`

请求：`{ "query": "如何恢复服务？", "top_k": 5 }`。

- `query`：严格字符串，去首尾空白后非空，最多 2000 字符。
- `top_k`：严格整数，默认 5，范围 1 至 20；拒绝布尔值、数字字符串和未知字段。
- 响应：`metric`、`model`、`dimensions`、`results`。
- 每条命中：`chunk_id`、`document_id`、`document_name`、`chunk_index`、`content`、`start_char`、`end_char`、`distance`。

字符范围使用解析文本中的从 0 开始、左闭右开区间，不是原文件字节偏移。响应不公开存储目录或向量数组。候选不足时返回实际数量，不补齐至 `top_k`；候选存在也不等于它们足以回答问题。

错误约定：归属不匹配或知识库不存在 `404`；模型身份不匹配 `409`；参数错误 `422`；模型调用或结果异常 `502`；配置缺失或无效 `503`；模型超时 `504`；知识库数据状态异常或命中距离无效 `500`。错误及日志不包含问题正文、密钥或模型原始响应。

接口复用已有模型配置依赖。配置缺失时，即使目标知识库为空，仍返回 `503`；只有配置正常时，服务才可跳过空库的模型调用并返回 `200` 和空列表。

## 验证与当前边界

使用可控制的查询向量和真实 PostgreSQL/pgvector，验证范围先于取前几名、距离排序、同距离顺序、来源字段、状态过滤、空结果、模型配置冲突、事务外调用以及安全错误映射。无需新迁移或依赖。

测试替身验证计算和业务边界，不能证明百炼真实向量的语义质量。学习者暂未配置密钥，真实语料的召回率与延迟尚未验收。当前没有回答生成、证据充分性判断、混合检索或重排。工作空间与知识库筛选只限定数据范围，仍不能代替身份认证和权限校验。
