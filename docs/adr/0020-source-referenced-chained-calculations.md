# ADR 0020：来源引用式用户数值与有界链式算术

- 日期：2026-10-11
- 状态：已采用；程序测试与真实模型、业务语义验收分开。

## 背景与选型

阶段 4.1 将“三次”保存为已确认用户条件，但旧 calculator 仅接受两个原文数值。
新能力需要让用户条件参与运算，并让先前成功的计算结果作为后续操作数。

方案 A：模型从消息和计算历史中提取并提交 value。接入简单，但程序必须另行证明这个值
确实属于当前任务，不能把模型抄错的 4 当作用户确认的 3。

方案 B：模型只提交来源引用，程序解析实际数值。增加严格契约与绑定逻辑，但能统一拒绝
不存在的输入、引用与自由 value 同时提交，以及旧任务和未执行结果的引用。本轮采用 B。
学习者确认方案，理由主要复述导师的来源可核对性；尚未独立实现或完成新模块实践。

实现选择保留旧 calculator，另加 sourced_calculator，仅在会话入口注册。
也可直接扩展旧工具的输入联合类型，但会改变已验收的旧 schema 与提示词契约。
两个工具共享 Decimal 运算，不复制算术实现；没有引入表达式解析器、新数据库或框架。

## 输入与执行边界

- evidence：证据编号与包含一个完整数字的连续逐字引文。程序提取数字，复用原文、数字
  边界与十进制范围验证；模型不提供 value。
- user_input：field_name 与确认该值的 request_id。只查当前任务的确认输入，重新验证
  非负整数、原始回复与单位匹配，保留 unit、raw_text 与 user_message 来源。
- calculation：当前运行中先前成功的 calculation_id。程序查真实结果，保留其值及舍入
  信息，不接受模型提供结果值，不展开递归公式树。

context 的近期聊天只是语言背景，不能授权操作数。服务层从数据库 PendingTask 传入
已确认输入和核对过的原文；运行控制器持有本次成功计算，不接受调用者传入旧计算池。
首个计算不可能引用计算 1，后续只能引用已成功分配的编号，失败不占编号。
结果引用不能形成自引用、前向引用或环；工作流仍是顺序有界循环，不是任意 DAG 引擎。

原文输入仍最多十二位整数、六位小数；用户输入为 0..9999 整数；派生结果最多二十四位
整数、十二位小数。结果超限明确失败，不截断。每轮最多一次工具，最多八次决策、七次
成功计算，末轮必须结束，重复参数保护继续生效。

共用局部 Decimal 上下文，不经过 float；除法最多八位小数、半偶舍入。链式运算使用
保存的舍入值，不能恢复精确分数。rounded 只表示本步除法是否舍入，输入的舍入信息
单独记录和展示，不把最终 rounded=False 当作整个链没有舍入。

## 会话与持久化

仍按消息接口提交，新增 mode=execute。只允许 ready 状态，执行使用保存的原问题，
消息 content 只是执行请求的审计文本，不能改次数、公式或原文。
不在接收“三次”的同一请求自动执行，便于区分条件确认与外部模型调用。

执行前及写回前核对规则快照。恢复执行不注册 ask_user，不能替换已有待办；仍可搜索
补充本知识库原文。恢复时原文预算超限返回冲突，模型配置故障保留原状态。
没有任何成功算术即 finish 时返回 calculation_required，不走普通回答模型绕过工具。
末次计算失败而未纠正时返回 calculation_error，不能把已有局部成功当最终结果。

公开运行结果与执行轮次共同原子提交，保留已确认任务。执行成功与失败后会话均仍为
ready：run.completed 只表示本次有界算术运行结束，不是原业务问题已全部解决。
新执行请求重新开始空计算池，不把以前执行的编号导入本次运行。
已提交的相同请求重放原结果；不同请求并发仅一个版本提交；事务外调用可能重复，
提交失败后重试也可能再次付费，不承诺外部调用 exactly-once。

迁移 20261011_0006 仅扩展 ConversationTurn 的 mode 检查约束，不改变旧消息。
存在 execute 记录时拒绝降级，不删除或伪装执行历史；无需回退时不要运行 downgrade。
阶段 4.1 历史响应的旧 execution_deferred 字面值继续可读。新确认响应改为
explicit_execution_required。默认 continue/new_task 请求摘要格式保持兼容。

## 输出与不解决的问题

计算结果由程序展示；只引用原文输入，用户消息与派生结果不是企业原文。
所有成功算术记录都保留，因此追溯链条无需递归嵌套结果对象。

新工具不接受自由常数、公式文本、百分比、指数、单位换算或任意代码执行。
来源真实不等于公式正确：120 × 3 的算术是 360，但不是月费十二个月的证明。
输出明确限定为算术说明，不声称业务任务完成。当前不自动产生“全年费用 1530 元”。
十二个月计费是否适用、多个业务条件补充、单位兼容及金额最终舍入政策均留到后续模块。
真实模型选择正确字段、正确公式、完整步骤和 finish 的能力仍未验收。

## 验证

见 test_sourced_calculator.py、test_conversation_execution.py 和迁移测试。
纯测试覆盖来源伪造、自由值夹带、前向引用、跨运行引用、故障后恢复、舍入继承、
结果范围、步数与重复保护、模拟原生配对；独立 PostgreSQL 验证跨请求恢复、重放、
并发、规则变化及提交回滚。完整回归结果见学习记录，不把测试数量当真实任务成功率。
