# ADR 0023：显式白名单与本地只读 MCP 知识搜索

- 日期：2026-10-12
- 状态：已采用，实现已接入，程序验收完成；真实非空向量/模型端到端质量未验收。

## 背景

既有 Agent 使用 ToolRegistry 执行进程内知识搜索与受限计算器。需要学习并实现 MCP
工具接口，但不应让服务器新增工具自动扩大 Agent 能力，也不能把协议成功当来源可信。
学习者选择 B，独立说明删除工具不能随便使用，需要用户批准。导师补充能力准入与
具体操作的身份/资源权限/确认是两层边界；当前只读实现没有删除或审批能力。

## 方案比较与决定

发现即注册减少新增工具的适配成本，却会把远端更新与平台执行权限绑定。显式白名单
需要批准工具并维护契约，但一个工具的行为能够直接解释和测试。采用后者，只批准
knowledge_search，并严格比对固定 inputSchema/outputSchema；其他定义不注册，
不发给模型。readOnlyHint 仅作为注解，不当授权或强制只读保证。

手写协议省依赖，但要自行维护初始化、传输、消息与退出；使用官方 SDK 增加依赖，
能够将精力集中在 Host 准入与证据边界。采用官方 Python SDK，项目固定 mcp==2.3.0。
使用低层 session.call_tool 单次调用，避免高层自动补充输入或 schema 变化重发。
SDK 默认 auto 先 server/discover 探测，必要时 fallback initialize 协商；该协议连接
行为不等于 tools/call 自动重发或故障时改用本地业务搜索。

本地 stdio 适合当前单机教学，不需要远端认证部署；远端 HTTP 更适合共享服务，但
需要网络、TLS、身份及权限。本轮固定当前 Python 启动 app.mcp_tools.server，不支持
任意命令/地址。每次搜索一个短命进程，不共享跨 event loop 的 Session；代价是启动
开销，连接池留到有测量或部署需求后，不宣称当前更快。

## 模型可见能力与入口

仅单次 `/agent-runs` 新增 search_backend=local/mcp，默认 local；MCP 支持 vector/hybrid。
MCP 与 rerank=true 同用返回 422，不静默改变请求策略。`/search`、`/answers` 和持久
会话入口不改用 MCP，既有偏好作用范围不变。原本地计算器保留，不经过 MCP。

模型仅填写 query。工作空间、知识库、策略、工具定义和子进程命令均由 Host 控制；
工具协议的输入契约复用 SearchArguments，输出 SearchEnvelope 固定版本和完整来源字段。
每次发现必须是完整无分页列表，最多 32 工具且名称不重复；knowledge_search 必须
唯一、输入/输出 schema 与本地批准契约严格相等。契约升级需要同步开发，不自动兼容。

## 原文可信与应用层预算

Client 拒绝不完整、错误、无结构化内容或附加内容结果，仅接收与结构化 JSON 一致的
单个文本块。不接受远端返回的自由指令、图片或链接作为来源。

Host 在调用后短事务重新核对工作空间/知识库、检索策略、文档 ready/块向量非空，
以及文档 ID、名称、块 ID/序号、完整正文与字符范围。任何一项不符整批拒绝，避免
部分证据已接受后再发现坏项。调用期间数据库变化仍回验，外部调用不占 Host 事务。
来源一致不证明排名最佳或正文能支持问题；距离与排名仅为检索元数据，答案继续引用校验。

应用层最多 100000 UTF-8 字节、5 个命中、12000 正文字，拒绝重复来源、额外字段和
非法/非有限数。字节上限在 SDK 解码后检查，不是解码前内存保护或操作系统资源隔离。
子进程是可读取必要配置的受控本地程序，不是安全沙箱，不用于任意第三方工具执行。

## 生命周期与故障

默认连接/发现/调用预算 30 秒，EAAP_MCP_TOOL_TIMEOUT_SECONDS 为正数且不超过 180。
超时触发取消，SDK 退出与进程清理还有有界宽限；预算不等于完整请求严格墙钟上限。
不把子进程 stderr 或第三方异常正文传播到公开响应，错误映射固定工具观察。

MCP 不静默 fallback 到本地搜索，不自动重发。Agent 可在既有步数与重复动作保护内
选择不同查询继续运行，那是新的模型动作，不是底层自动重试。无成功证据时技术失败
不会变成成功弃答，既有 completed/stopped/failed 区分保持。

## 验证、影响与未解决问题

程序验证分为纯契约/替身、官方 SDK 内存协议、公开固定资料的真实 stdio 子进程、
生产固定 app.mcp_tools.server + 真实 stdio + 独立 PostgreSQL 空知识库链路、MCP
Client 替身的 Host 非空回验，以及完整后端回归。公开进程 fixture 不调用数据库或
模型；生产空结果链路不请求真实向量/模型；Host 反例的 Client 与模型为替身，不能
合并称真实非空向量/模型端到端联调。

最终协议专项 **95 项通过、无跳过（13.02 秒）**。最终完整后端回归 **1501 项通过、
无跳过（482.40 秒，0:08:02）**，独立 eaap_test PostgreSQL 与模拟/受控模型；新增
MCP 140 项（95 协议、45 API）。专项是全量子集不能相加，阶段 4.4 的 1361 项保留
历史含义，收集数不算通过。早次协议 85 项通过/1 项失败（12.41 秒）、组合专项
180 项通过/1 项失败保留：早退异常断言未适配 SDK 嵌套 ExceptionGroup，修为严格
检查全部叶子 ConnectionClosed 后专项和全量通过，不把修复前记为全部通过。

另一次新增九个 public_error_code 用例后的定向纯协议运行为 **88 项通过、4 项失败、
3 项 deselected（3.80 秒）**；真实 stdio 三项仅当次排除，不是最终跳过。四项失败
发现生产 Client 对 SDK 请求超时与嵌套异常组归类不正确；已修 public_error_code
递归展开异常叶子，全部超时映射 mcp_timeout，仅保留一致已知安全码，未知或类别
混合固定 mcp_service_error，不传播异常正文。随后 95 项协议专项和 1501 项全量
通过，保留这一生产修复，不能将本轮描述为只修早退测试断言；定向结果不与全量相加。

无需新迁移，schema 保持 0008。新增 SDK 的 PyJWT 等依赖不是本项目已实现身份认证。
本轮不开发删除、用户审批、远端 MCP、任意命令、通用插件、多租户权限或资源沙箱。
尚未验收真实向量检索 child 与真实模型规划/生成整条链路，不报告语义改进或任务成功率。
本轮真实模型调用为零；学习者方案与独立理由已确认，代码实践及三道面试题讨论仍未
完成。重要文档和学习记录同步，用户代码实践与面试独立计分。安全检查后按模块本地提交，
GitHub 推送另行授权，不改写历史。
