### 当前实践

场景：已上传的产品说明需要切块，AI 回答必须指出来源文档和段落，并能找回原文。

学习者先列出每个文本块的最少必要信息，按“字段 → 用途”说明，暂不考虑向量字段。导师根据具体方案评价正确与不足，比较两种可行设计，再落实数据结构与测试。

通过本步的标准：能从保存的文本块追溯原文，并独立解释所选字段为何必要。后续切块测试也应证明同一文档与同一配置产生相同结果。

后续每小步按照“提出方案 → 实现或故障模拟 → 测试证据 → 独立复述与面试追问”推进。面试题逐个提出，先回答再反馈。
