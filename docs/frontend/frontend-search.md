# 网页第八步：知识库候选段落检索

2026-10-16，起点 `9a8b298`。在已有资料入库网页上接入后端已有的知识库检索接口。

## 目标与方案

从知识库文档列表进入检索页，手动输入问题，查看最多 3 个候选原文段落。
学习者选择 A 独立检索页；B 是把表单放在文档列表中。
集中问题与候选、明确知识库范围的理由由导师说明，记录为方案确认，不记独立完整设计。

入口位于文档页标题附近，独立页保留工作空间、知识库名称及“返回文档列表”。
检索范围为整个所选知识库的可检索文档，不要求先选择文档，也不限于列表第一页。
入口不按当前页的 ready 数量禁用；列表正在读取、上传、退出或存在错误时禁用。
本步复用既有组件及请求隔离方式，不增加路由框架、数据库结构或后端检索策略。

先看检索证据，随后再接生成答案和完整引用；本步不请求 answers、Agent、混合检索或重排。
既有 CLI 的参数、等待、来源核对和不自动重试政策直接复用，不再重复要求方案确认。

## 问题输入与请求

进入页面与输入文字不发送检索请求。点击“检索”后，去掉首尾空白，
按 Unicode 码点校验为 1..2000 个字符；提交期间禁用输入与重复提交，保留停止等待和返回。
App 同步 pending 锁覆盖检索 POST 和全部来源 GET，不在 POST 返回时提前释放。

只发送一次 `POST /api/v1/workspaces/{workspace_id}/knowledge-bases/{knowledge_base_id}/search`：

```json
{"query":"本次问题","top_k":3,"strategy":"vector","rerank":false}
```

复用同源 HttpOnly Cookie、`X-EAAP-Web`、禁止缓存和重定向，不读取 Token 或模型配置。
POST 等待最多 330 秒；来源详情 GET 每次仍为 10 秒，不是整条链的严格总时限。
后端继续核验成员与父子范围，只从 ready 且向量非空的块中检索。
检索可能为问题调用向量服务；进入页、重排或生成答案均不自动执行。

## 先核对完整结果，再展示候选

API 接纳层要求 HTTP 200、vector/cosine_distance、无重排、最多 3 个候选。
非空结果的模型名必须有效且维数为 1024；空结果允许模型与维数同时为空，或有效模型与 1024。
严格核对 UUID、块 ID 唯一、同文档名称一致、正整数块序号、正文及字符范围一致，
正文总计最多 100000 个码点；距离必须为有限的 0..2 数值并按非递减顺序返回。

整批结构通过后，按唯一文档 ID 在所选知识库路径读取详情，核对 ID、父级、名称和 ready 状态。
同文档多块只复核一次；所有来源通过前不展示任何候选正文。
这层客户端核对不替代后端授权，也不表示逐块重新核验数据库原文。

结果保存提交时已去空白的问题快照，之后编辑输入不会改写旧结果对应的问题。
每次新提交先清除旧候选；每段展示文档名、块序号、字符范围、四位小数的余弦距离及前 300 个码点。
正文按 React 文本转义；不显示内部 UUID、任意错误正文或 HTML 渲染结果。
距离越小仅表示向量越接近，不是正确率；预览截短不代表完整块被截短。
空候选是正常结果，不代表知识库没有文档、没有相关资料或本次零费用。

## 故障、停止等待与会话

POST 401 清理会话、问题和资源上下文；403/404/409/422 只显示固定安全拒绝提示，
不把 404 显示成空候选，也不依据失败响应承诺没有费用。
网络、超时、其他异常状态、无效响应或任一来源核对失败均为整体结果未确认，不自动重试；
来源 GET 的 401 仍清理会话，不能被一般来源故障吞掉。

停止等待中断浏览器请求并隔离迟到结果，不保证后端停止或没有费用。
返回、切换知识库、退出或登录到期沿用 AbortController 与请求序号，
同一隔离范围覆盖 POST 与全部来源 GET。退出中断后若退出失败，保留检索未确认及退出故障，
不恢复已被中断的旧候选。检索不延长固定登录期限，问题与结果不跨刷新持久化。
