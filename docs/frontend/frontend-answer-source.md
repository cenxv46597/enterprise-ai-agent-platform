# 引用问答：手动查看完整来源段落

2026-10-22。上一环节是ready文档处理页进入整库引用问答，其一个实践与两题已收尾。本轮按用户继续开发学习的要求，补齐阅读回答后的来源上下文核对。

## 业务场景与选择

回答中展示的引文通常只是一句话，用户需要看到所在段落，判断前后是否有适用条件或例外。新入口位于每条引文下，默认不读取；用户点击后展示该引文所在的一个完整文本块并标亮引文，不展示整份原文件。

沿用App统一管理请求、KnowledgeAnswer负责展示的惯例，复用全局取消/序号/登录失效处理。来源状态附在已确认答案的UI状态中，新问题、返回或切换范围自然清理，避免把上一答案的来源挂到新答案。

复用已有文档详情与文本块列表两个GET，不新增后端端点。代价是一次读取这份文档的完整块列表，前端只投影所选块；现有响应数量与字符上限仍有效。未来若大文档传输成为实际瓶颈，可另做单块读取接口，本轮不扩展。

## 来源核对与边界

先重新核对当前知识库路径中的文档ID、名称、ready状态，再按块ID找到块，核对父文档与块号。引用的全文字符范围须落在块内，按Unicode码点精确切片后逐字等于引文；不能只检查“正文包含这句话”，因为同一句可能出现多次。高亮采用同一字符位置，原文始终按React文本展示。

该核对只说明**这条引文与本次读到的来源块匹配**。即时问答没有生成时完整块的前端快照，不能证明整块内容未变、其他引文一致、跨两个GET原子一致，或答案语义正确。已确认答案保留原提交问题，不因输入编辑而改写。

一次只查看一个来源区。新读取先清旧正文；读取期间禁用新生成与其他来源按钮，保留停止读取、关闭和返回。失败或取消只影响来源区，原确认回答保留；401清会话。关闭、返回、退出（包括退出失败）、固定期限到期和新问题不会恢复旧正文或旧编号，迟到响应被隔离。

HTTP错误只展示实际失败GET的合法排错编号；成功响应不提供兜底编号，本地身份/正文核验、网络或取消不造编号。读取只用GET，不重新检索、生成、切块或向量化，也不自动重试。

## 验证与教学停点

新增API校验38项、App集成13项，最终定向**2文件51项通过（4.91秒）**；完整前端**32文件1189项通过（62.97秒）**，TypeScript及生产构建通过（269毫秒）。各隔离入口`final_exit=0`，临时工具配置删除，项目环境文件加载禁用。首轮50项中9个UI断言因同一问题同时在输入框和提交快照出现而歧义失败；改为在回答结果区核对，并补关闭后重开同一引用的隔离场景，再获得上述结果，不把首次失败报绿。

覆盖显式doc→chunks两GET、完整长正文、emoji和重复句精确位置、同块多引文各自高亮、HTML作为文本、错父级/块号/状态/正文拒绝、目标复制、HTTP失败编号无回退、超时/取消/关闭重开/新问题/返回/退出失败/401/到期及迟到隔离。没有后端代码、数据库连接/测试或真实浏览器新验收，未发送真实检索、向量或生成请求；前端模拟结果不证明真实全链路或答案质量。
