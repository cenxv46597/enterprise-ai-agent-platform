# 网页第九步：独立引用问答页

2026-10-17，起点 `a229a7b`。在已有知识库文档页上接入现有 `/answers`，
不重做后端 RAG、CLI、身份或数据库结构。上一步见[候选检索](frontend-search.md)。

## 目标与页面方案

从知识库文档页进入“引用问答”，手动输入问题，展示回答与完整引文；证据不足时明确弃答。
比较 A 独立问答页与 B 在候选检索页增加问答入口，学习者确认 A。
集中展示问题、答案和引用的取舍由导师说明，记录为选项确认，不记独立完整设计。

问答覆盖当前知识库全部可检索文档，不限于列表第一页，不要求先选择文档。
即使当前页 ready 数量为零，也不能据此禁用问答；列表读取、上传、退出或错误期间入口禁用。
继续使用已有 React 页面状态，不新增路由框架，不持久化问题、结果或所选知识库。

## 调用链与证据

进入页面和输入均不请求模型；点击“生成回答”才提交去空白后 1..2000 个 Unicode 码点的问题。
只发送一次当前知识库的 `POST /answers`：

```json
{"question":"本次问题","top_k":3,"strategy":"vector","rerank":false}
```

不先调用 `/search`，也不把上一次候选预览当作本次生成证据。
后端统一执行范围内检索、完整上下文选择、生成与逐字引文校验。
上下文沿用后端完整块预算，网页检索的 300 字符预览不进入生成请求。
`top_k=3` 限制候选块数，不限制为最多三条引用；同一块可引用不同句子。

复用同源 Cookie、`X-EAAP-Web`、禁止缓存和重定向的选项，后端继续核验成员与父子范围。
正常有证据路径沿用既有服务：最多一次问题向量 HTTP 和一次生成 HTTP，不重排、自动重试或修复重试。
空候选可直接弃答且不调用生成服务；弃答本身不证明本次零费用。
本轮开发只使用模拟请求，没有新的真实任务授权或费用证据。

## 接纳与完整引用

仅接纳 HTTP 200：非空白答案最多 4000 码点、严格布尔弃答标志、最多 20 条引用，且无重排 trace。
正常回答至少一条引用；弃答必须没有引用。HTTP 弃答也包含非空提示文字，
与模型内部草稿的空答案约定不同。接口故障、坏引用或来源失败不显示成正常弃答。

逐条核对 UUID、1..255 码点文档名、正整数块号、1..1000 码点非空白引文，
以及非负安全整数 `[start,end)` 与引文码点长度一致。
同一文档名称须一致，同一块的父文档和序号须一致；拒绝重复 `(块ID, 引文)`，
允许同块不同引文。只保留展示所需字段。

整批通过后，按唯一文档 ID 在当前空间/知识库路径 GET 详情，核对 ID、父级、名称与 ready。
同文档只读一次；全部来源成功前不显示答案或任何引文，弃答无需来源 GET。
这层核对不替代后端授权，也不等于网页重新逐字回验块正文或证明答案语义正确。

结果保存提交时的问题快照，随后编辑输入不改写旧结果问题；新提交先清旧结果。
答案与完整引文按 React 文本渲染，保留换行，不解析 HTML，不采用检索的 300 字符截短。
展示文件名、块序号与引文在解析文本中的字符范围；范围不是整个块或文件字节位置。

## 等待、故障与会话

问答 POST 浏览器等待最多 630 秒，来源 GET 各自仍为 10 秒；不是整条链严格总时限。
同步 pending 锁覆盖 POST 和所有来源核对，防止点击两次或来源尚未完成时再次提交。

401 清理登录、问题与资源状态；403/404/409/422 显示固定安全拒绝信息，不回显原始错误正文。
网络、超时、取消、其他状态、无效成功响应或任一来源失败统一提示“问答结果未确认”，
可能已调用向量或生成服务，不自动重试；来源 GET 的 401 仍清理会话。

停止等待只取消浏览器等待，不保证后端停止或没有费用。
返回、切换范围、退出和固定到期沿用取消信号与操作序号隔离迟到结果。
退出中断问答而退出失败时，保留问答未确认及退出故障，不恢复被中断的答案。
ADR0030 固定 30 分钟不续期；重新挂载不保留问题和答案。
