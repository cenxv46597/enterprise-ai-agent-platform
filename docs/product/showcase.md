# 产品场景与界面

## 从制度资料到有出处的回答

使用[公开虚构差旅制度](../delivery/demo-policy.md)，可以演示以下流程：

1. 创建工作空间和知识库，上传资料并观察解析状态。
2. 手动切块、按预算生成向量，将资料变为可检索状态。
3. 问“普通员工住宿能报多少”，核对450元、发票和提前书面批准等条件。
4. 展开引文所在完整文本块，确认回答是否遗漏限制，再导出本次问题、参数、答案和引文。
5. 问“审批通过后银行几天到账”，检查系统是否识别原文未规定，避免把审批通过说成已到账。

上述是演示材料和预期检查点，不是本轮新增真实模型验收结果。外部模型调用需配置服务并明确费用预算。

## 受控任务与固定工作流

会话入口可以收集任务缺失条件，并在规则和字段满足要求后执行标准费用估算。
固定问答工作流支持显式创建、执行、保存检查点、有限恢复和读取保存答案。
这些能力适合展示工具约束、版本控制和故障后的结果核对；目前没有通用审批或任意任务自主执行的承诺。
