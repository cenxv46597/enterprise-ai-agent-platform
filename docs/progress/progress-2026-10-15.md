## 今天完成了什么

1. **HTTP 客户端故障提示与操作统一。** 在昨日登录/三级资源浏览客户端上，区分连接失败和登录超时，
   排查 Docker 未启动、后端旧进程以及 CMD/PowerShell 混用的问题。后续给学习者的命令统一为 CMD。
2. **上传与切块。** 客户端读取本地文件并 multipart 上传；后端保存解析，独立选择已有文档切块。
   学习者实际上传 `demo-export-records.md`，切块返回 8 块；parsed 表示已解析，不代表可以检索。
3. **有明确预算的向量化。** 增加显式 `--embed --max-chunks N` 和服务端请求上限；不自动重试。
   学习者实际生成并保存 8 块、1024 维向量，文档变为 ready。上限约束本次新生成，不等同并发费用恰好一次。
4. **检索与带引用问答。** 独立 `--search` 展示最多三个候选及来源；`--ask` 向已有 answers 接口发送问题，
   由后端检索、选择完整块送入生成，客户端展示完整引文。客户端检查返回结构、引用和父级范围；缺引用的非空答案不展示。
5. **网页入口与登录保持。** 新增 React + TypeScript + Vite，连接已有后端，展示本人工作空间第一页。
   初版内存 JWT 后，根据学习者希望关闭浏览器后仍保持一段时间的需求，改为 HttpOnly 持久 Cookie。
   沿用固定 30 分钟期限，恢复不续期；后端复验身份和成员范围，保留 CLI Bearer。
   新增来源校验、退出确认及失败重试、过期处理、迟到响应隔离。

对应代码入口：`backend/scripts/browse_demo.py`、`backend/app/api/auth.py`、
`backend/app/auth/web_session.py`、`frontend/src/api.ts`、`frontend/src/App.tsx`。
详细说明见[上传](../cli/demo-upload.md)、[切块](../cli/demo-chunks.md)、[向量化](../cli/demo-embeddings.md)、
[检索](../cli/demo-search.md)、[问答](../cli/demo-answers.md)、[网页登录恢复](../frontend/frontend-session.md)和 [ADR 0030](../adr/0030-persistent-web-cookie-session.md)。
