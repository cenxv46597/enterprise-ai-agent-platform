## 5. 已完成与验收证据

### 阶段 1：RAG 基础与评测工具

已实现资源元数据、单文件保存与 UTF-8 解析、只读存储对账、确定性字符切块、整批事务与重试复用、向量保存、知识库范围检索、生成答案、原文引用与证据不足弃答。外部模型请求放在数据库事务之外。

### 阶段 3：Agent 与工具基础

3.1 有界 Python 循环：注册工具、结构化决策、执行观察、去重、证据快照与预算、完成/停止/失败。`max_steps` 是决策次数，最后一轮工具请求在执行前停止。默认 4、最多 8；只在内存保留运行状态，没有跨请求幂等或恢复。

3.1 的 868 项测试分段验证通过：首次 695 项通过后出现本机数据库 TCP 连接错误；从失败项起复测全部剩余 173 项通过。不能把它描述成一次完整无故障运行，根因未确认。

3.2 默认原生协议：严格单调用、完整 JSON 参数、编号唯一、请求与结果配对、时间和体积界限。旧 JSON 适配器供显式选择，不自动切换。DeepSeek 官网请求关闭思考模式，不保存内部思考。完整回归 921 项通过、无跳过，使用模拟模型与真实独立数据库，没有新增付费调用。

3.3 受限计算器：仅加减乘除，两个十进制原文操作数，整数最多 12 位、小数最多 6 位；除法 8 位半偶舍入。完整原文数字边界核对，派生结果独立记录，不包装成 `GenerationSource`。计算收尾由程序返回算式和输入原文引用，不调用生成模型；末次计算失败则 `failed / calculation_error`。普通问答保持原生成路径和 `/answers` 契约。
