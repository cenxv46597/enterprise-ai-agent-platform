# 虚构企业差旅制度：求职演示专用

本文件仅供软件功能演示，不是现实企业政策或报销依据。版本：DEMO-2026-10。

## 住宿标准

普通员工国内出差，住宿报销上限为每人每晚450元。住宿必须提供合规发票。
超过450元的部分，只有出差前获得部门负责人书面批准后才可报销；未提前批准时按450元上限处理。

## 提交时限与材料

员工应在出差结束后的10个工作日内提交报销申请。申请应包含出差审批记录、发票和费用明细。
资料不齐时，财务通知补充材料；本制度没有规定补充材料的办理时限。

## 状态与到账

审批通过表示申请已获得批准，不等于银行已经到账。本制度没有规定具体到账日或银行处理时长。
