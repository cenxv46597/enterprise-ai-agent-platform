# 演示第六步：生成有引用的资料回答

资料问答主线接上最后一环：输入问题 → 后端检索 → 选择完整证据块 → 生成草稿 →
校验引文 → 展示答案与来源。复用已有后端能力，本轮只增加客户端操作与模拟测试，
没有新 API、数据库迁移、Agent 或会话功能。

## 学习与设计

上一小步真实检索已命中答案所在的第 1 块，但该句在第 436 字符之后，终端只预览
前 300 字符。导师指出位置后，学习者选择传完整候选块，并解释预览可能遗漏信息。
这是给定场景下的理由说明，不记为独立完整 RAG 设计或本人代码实践。

后端现有 `select_context` 按排名选择能完整放入正文预算的块；放不下则跳过并继续，
不截掉块尾。默认 12000 字符、配置最高 50000，预算不含问题、提示词及模型 Token。
不是无条件发送全部候选，也不使用终端 300 字符预览作为模型证据。

客户端可自行组织检索结果，也可请求后端统一处理。本轮沿用后者：只 POST 一次
`/answers`，不先执行 `/search`，避免多做一次问题向量化。先前检索操作及其授权不
覆盖本次新问答，不能声称直接复用了上一次请求的候选快照。

## 操作与结果

新增 `--ask`，与上传、切块、向量化、检索互斥，不接受 `--max-chunks`。
登录并选择工作空间、知识库后，交互输入 1..2000 字符的问题；不选文档。
请求固定 `question`、`top_k=3`、`strategy=vector`、`rerank=false`。
检索、完整上下文选择、生成和逐字引文验证都由既有后端统一执行。

正常有证据路径最多一次问题向量 HTTP 与一次生成 HTTP，无重排、自动重试或格式
修复重试。没有候选可直接弃答，不调用生成模型；空响应不能据此普遍证明零向量费用。
生成输出沿用服务器配置，CLI 没有另设 Token 或金额预算。

客户端核对非空且不超过 4000 字符的答案、严格布尔弃答标记及最多 20 条引用。
正常回答至少有一条引用；弃答必须没有引用。公开 API 弃答仍含固定非空提示，不能
套用模型草稿中“答案为空”的规则。正常弃答退出码为 0，并显示“证据不足，本次弃答”。

引用核对 UUID、文件名、正整数块序号、1..1000 字符引文、范围与引文长度一致、
重复引用及同块身份一致；同一块的不同引文允许，3 个候选不代表最多 3 条引用。
全部引用文档均通过所选知识库路径的详情复核（父级、ID、文件名、ready）后，才
展示任何答案和引文。同一文档只读一次详情，复用检索操作的来源复核函数。

展示文件名、块序号、完整引文及引文在解析文本中的 `[start,end)` 范围，范围不是
整个块的范围。答案和引文先脱敏再转义，完整引文不套用检索预览的 300 字符截断。
后端逐字校验引文属于本次证据块；客户端没有重新读取块正文，不能声称独立回验原文。
即使引文存在，也不保证回答的每个语义结论都受支持，仍需人工检查。

问答 POST 单独等待读取 630 秒，连接、写入及其他请求仍为 10 秒。
两类服务各自总等待预算配置最高 300 秒，630 秒不是整个 API 的严格结束期限。
超时、中断、5xx、无效成功响应或来源复核失败均提示结果未确认，可能已调用模型，
不自动重试。坏引文等后端故障不能伪装成正常弃答，客户端不输出未经确认的草稿。

## 验证与后续

2026-10-15，原客户端 79 项、检索 20 项与新问答 22 项联合专项 **121 项通过、
无跳过（1.80 秒）**，不与历史相加。全部 MockTransport，无数据库或真实模型，
临时文件仅用于既有上传测试；未重跑后端全量或把模拟结果当作真实回答质量。

验证固定范围/参数、仅一次 answers 请求、独立 630 秒等待、正常弃答、非法问题、
答案/引用关系、相同块多引文、全部来源通过前禁止展示、完整长引文及安全输出、
失败不重试、空范围和互斥参数。`--help` 正常。本轮实现与测试由导师团队完成，
本人代码实践和真实问答操作仍待。

下一次拟对同一问题“导出清单中的一个条目包含哪些信息？”只执行一次问答，
最多一次向量 HTTP 和一次生成 HTTP，不重排、不自动重试；真实任务与预算尚待确认。
