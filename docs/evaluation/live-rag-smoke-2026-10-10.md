# 首次真实 RAG 链路验证：2026-10-10

## 本次完成了什么

使用本机 PostgreSQL/pgvector、百炼 `text-embedding-v4`（1024 维）与 DeepSeek `deepseek-flash`，完成上传、解析、切块、向量保存、限定知识库检索、回答或弃答及引用定位。执行入口是 FastAPI `TestClient`，应用依赖没有换成模型或数据库替身。

本次采用[虚构产品运维说明](../../examples/knowledge/demo-product.md)和[六个固定问题](../../examples/evaluation/rag-smoke-cases.json)。公开语料没有真实企业数据；其中的 PDF 支持、10 MB 限额、令牌权限和备份功能都是虚构产品设定。当前项目实际只支持 UTF-8 文本和 Markdown 单文件上传，默认上限 5 MiB，尚未实现这些虚构功能。

完整输出保存在[原始应用响应报告](live-rag-smoke-2026-10-10.json)，含问题、检索排名、距离、答案、引用及耗时。记录的是请求模型名，没有收集服务商返回的模型快照名、token 用量或账单费用。

## 结果及逐条复核

语料按 500 字符、重叠 50 字符切成 5 块，首次生成并完整保存向量耗时 2.090 秒；恢复运行复用原文档和向量，文档状态为 `ready`。六题均完成，4 题回答、2 题弃答，全部符合预期的弃答标注。回答共返回 8 条引用，文档 ID、引文与原文字符范围均校验通过。

以下结论来自 AI 导师逐项对照原文的辅助复核，不能代替独立人工验收，也不表示学习者已经独立掌握评测：

- **服务重启：** 暂停导入、重启、等待运行、健康检查、检查通过后恢复导入的顺序正确。超时处理和失败任务手动重试均有原文支持。
- **上传格式：** 保留了 UTF-8 和可提取文字 PDF 的条件，不支持的格式及限额与虚构说明一致。
- **令牌失效：** 生成、替换、检查通过后撤销旧令牌的条件正确。“重新加载配置”放在末尾补充，表达顺序可以改善；未明确声称它在健康检查之后执行，因此本次不判为事实冲突。
- **备份恢复：** 成功快照、维护模式、执行恢复、核对后退出的顺序与条件正确，覆盖内容和快照后修改需重新导入的风险也保留。
- **退款申请：** 只有审核后的到账时间，没有申请步骤，正常弃答合理。
- **支付币种：** 无支持具体币种的证据，正常弃答合理。

没有发现这四份回答包含无依据的事实。词语命中仅是阅读提示；两个弃答没有命中题集中的提示词，但通用弃答措辞表达了资料不足，不应据此判错。

六次 `/answers` 路由的单次耗时分别为 7.010、2.968、4.468、8.706、2.189、1.948 秒，范围 1.948～8.706 秒。它包含问题向量生成、数据库检索、回答模型及校验，不是纯模型延迟，也不是 P95。独立 `/search` 测量为 0.588～0.769 秒；两次路由分别生成问题向量，结果不共享查询缓存。

## 结论的范围

本次证明小型公开语料在实际供应商接口和本机数据库上能够完成业务链路。只有 5 块且每题 `top_k=5`，所有候选都会返回；这无法验证从大量干扰资料中挑选证据的能力，不报告 Recall@5 质量成绩。负例明确写出资料缺失，弃答也较容易，尚未测试含混缺失、冲突证据或提示注入。

答案和引用属于应用最终响应，不能据此区分模型原始草稿与程序后处理的效果。只执行一次，不构成稳定性、并发或性能基准。没有经过部署后的 HTTP 网关，也没有验证身份认证、权限或外部访问。

下一步在相同技术栈上扩展标注语料和干扰文档，分别检查预期证据是否被检索、答案是否忠于证据、弃答是否恰当，再判断是否需要重排或混合检索。

## 如何复跑

从仓库根目录运行，需已安装后端开发依赖、完成数据库迁移，并在本机 `.env` 配置两类模型。脚本只接受本地 `eaap` 数据库、仓库内上传目录和本次模型组合，数据库地址的查询参数会被拒绝。

本次机器上可复用已有演示数据，仅重跑一道问题：

```powershell
.\.venv\Scripts\python.exe backend/scripts/live_rag_smoke.py --run --resume --case-id restart_recovery_steps
```

每次重跑仍会请求查询向量和生成模型，产生 API 费用；成功条目会追加，不覆盖之前的观测。新机器或新演示应使用未存在的报告路径：

```powershell
.\.venv\Scripts\python.exe backend/scripts/live_rag_smoke.py --run --report docs/evaluation/my-rag-smoke.json
```

脚本失败时保存安全阶段信息；已保存资源可通过 `--resume` 继续。检查演示知识库只包含这一文档，并核对返回文本来自公开语料；不记录密钥、配置地址或供应商原始异常。保存报告成功前进程退出仍可能留下未记入报告的资源，当前没有自动清理机制。
