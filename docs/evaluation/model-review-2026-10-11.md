## 已验证的行为

- 问答请求保持原业务契约，评审请求使用独立 JSON 契约。
- 超时、限流和截断输出不自动重试，不泄露原始错误正文或密钥。
- 检查项缺失、假身份、错误答案绑定和捏造片段被拒绝。
- 一题超时继续后续题，该题质量结论为未知，不算答案不通过。
- 模型判为不通过时执行仍成功，AI 质量统计与技术失败数分别报告。
- 待审核和部分审核不进入 AI 已完成分母；AI 判断不进入人工质量分。
- 未配置评审服务不会自动借用生成服务的配置；计划模式不读取 `.env` 或建立 HTTP 客户端。
- 输入变化、超出调用预算或已有输出在调用前拒绝；单题选择只调用一次。
- 正常请求之间中断时，已完成题目的记录仍可读取，报告保持“运行中”。

模拟评审的判定是测试输入，不是对真实六题的模型评审结果。测试通过说明记录与控制逻辑符合契约，不能说明真实评审模型具备可靠语义判断能力。

## 证据范围

报告使用固定公开完整文档作为复核依据。旧问答记录没有保存实际生成上下文，不能宣称完全重建当时证据，也不能作为带干扰知识库的新问答成绩。

服务未返回 token 用量时保存 `null`；部分返回时只报告已知调用用量之和。没有计价规则，费用保持未知。本轮没有成本或模型质量比较数据。
