## 开发方式与贡献说明

项目采用AI辅助开发和导师式结对学习。主体方案、实现和验证较多由AI导师完成，学习者通过跟随实践、
独立回答、代码阅读和讲解逐步掌握。具体参与以对应记录为准，不将代码量或测试数量描述为个人独立开发经历。

历史记录中的“未推送”“下一步”“尚未教学”描述对应时点。最新代码、Git实际状态和当前交接优先，
不能把后续模块完成自动算作更早个人练习完成。
